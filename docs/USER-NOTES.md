## Combat now

Fights run in rounds. Hosts break instead of vanishing. Fallen of yours go to the Infirmary until beds are full; the rest are gone. Build an Infirmary and use Treat on the War tab. No Infirmary means no beds.

## Hold layout

Staff buildings. Cluster same types. Pair farm/granary, lumber/sawmill, quarry/mason, mine/mint. Park work on the Keep edge. Barracks on the Keep edge trains cheaper.
