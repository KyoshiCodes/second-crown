## Holiday overlay

The bar at the very top of the page has **Holiday overlay**. It stays on screen when you scroll.
Pick All Hallows to preview Halloween. Pick None or Auto to leave.
The badge in the corner is a label, not the menu.

Music on plays the synth bed. Real songs play only if a file exists at `/audio/halloween.ogg` (see `packages/app/public/audio/CREDITS.md`).
