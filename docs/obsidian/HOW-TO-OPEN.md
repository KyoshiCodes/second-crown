# Open this vault in Obsidian

1. Install Obsidian.
2. Open folder as vault:
   `C:\Projects\second-crown-claude\docs\obsidian`
3. After `git pull` on `main`, this folder updates.
4. Do not put secrets in the vault. Repo can go to GitHub.

Optional: also attach the whole `docs/` folder as a second vault if you want CHANGELOG history.
